# beatrizmclm.github.io

Personal site for Beatriz Manso — bioinformatics and computational biology.

Live at **https://beatrizmclm.github.io**

Single static `index.html`, no build step and no dependencies. Edit the file
and push; GitHub Pages redeploys from `main`.

To add a CV: drop a `cv.pdf` in this directory and uncomment the
"Download CV" link in the footer of `index.html`.
